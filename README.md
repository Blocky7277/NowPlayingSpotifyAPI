# NowPlaying

A server that exposes an API that static websites can safely interact with to pull
a user's currently playing Spotify song.

## Build

```bash
$ git clone https://github.com/Blocky7277/NowPlayingSpotifyAPI.git
$ cd NowPlayingSpotifyAPI
$ go build
```

## Use

```bash
$ ./nowplaying
```

API hosted at [localhost:3000/api/now-playing](http://localhost:3000/api/now-playing) by default.
